Topsoil, Mulch & Gravel Delivery in Palatine, IL

Taking on a landscaping project yourself? BJ's Lawn Service delivers topsoil, mulch, and gravel right to your property so you have the materials you need without renting a truck or making multiple trips to the supply yard.

Tell us what you're working on and we'll help you figure out the right material and how much you need. We'll drop it where you want it so your project can get started right away. And if you'd rather not spread it yourself, we can handle the installation too.

Materials We Deliver

Topsoil

For filling low spots, leveling, new lawns, and building up planting beds.

Mulch

For refreshing planting beds, tree rings, and foundation plantings.

Gravel

For paths, drainage areas, and base material for home projects.

Optional Installation

Prefer not to do it yourself? We can spread and install the materials we deliver.
